# Ohne Bot
- Was????? A Slack Bot???? It's simple and doesn't do anything special,
  but cmon, it's funny! (even if it's not, please act like it is...) :D

## Usage
Ohne Bot features a few commands:
- /dsb-teststring -> Pretty much prints a simple check string to see if the bot is working.
- /dsb-pingpong -> Tests the bot response time.
- /dsb-funcatfact -> Tells a fun fact about cats.
- /dsb-extremelyfunnyjoke -> Tells an extremely funny joke (if it's not, at least act like it is...).
- /dsb-help -> Tells all commands and their usage.
This bot is available exclusively on the Hack Club workspace from Slack.
